# yolocoder starter

Vite + React + Tailwind on the frontend (port 5173, proxying `/api` to the
backend), Express + Drizzle + SQLite on the backend (port 3001).

```
scripts/start.sh     # start both, hot reload on
scripts/restart.sh   # stop then start
scripts/stop.sh      # stop both
```

Or just talk to yolocoder in the chat pane — it can run these for you and
will notice if something breaks while it's running.
